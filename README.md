# Wayback Crystals

Download on [Curseforge](https://www.curseforge.com/hytale/mods/wayback-crystals)

A Hytale plugin by Phillip Laue

Teleportation Crystals that allow players to teleport to a location they have set using a custom block.
If configured also allows teleporting back to the location the player was at when they warped using the crystal item.

Created using a Hytale plugin template by Up, and slightly modified by Kaupenjoe.
